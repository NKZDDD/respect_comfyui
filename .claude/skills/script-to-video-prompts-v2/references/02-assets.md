# 环节 4-6：资产提取与生产决策 → 资产生产与固定 → 段落资产绑定

---

# 环节 4：资产提取、定义与生产决策

## 目标

决定哪些视觉内容需要成为独立固定资产。**不是所有实体都值得生产**——这一环节的核心是过滤。

## 资产分类（九种）

| 类 | 说明 |
| --- | --- |
| 人物演化资产 | 人物的长期阶段（`-E` 层）：受伤留疤前/后、身份揭晓前/后 |
| 人物造型资产 | 阶段内的造型（`-A` 层）：便利店制服、晚宴西装 |
| 人物附属特征 | 胎记、疤痕、标志配饰——身份锚点，单独建资产 |
| 场景演化资产 | 场景的长期结构变化：被砸毁前/后 |
| 场景环境版本 | 同一场景的光线/时段/氛围版本 |
| 道具演化资产 | 道具的长期形态 |
| 道具状态资产 | 道具的状态版本：干净/带血/断裂 |
| 道具组合 | 成组出现的道具（Prop_Sets）：满车营养品箱 |
| 固定群体资产 | 反复出现的群体：围观顾客群、黑衣配送员组 |

## 生产决策（三分类）

| 决策 | 判据 | 例 |
| --- | --- | --- |
| **必须生产** | 长期视觉标准 / 跨段复用 / 重要身份识别 / 高连续性风险 | 女主各阶段造型、鸢尾花胎记、主场景 |
| **条件生产** | 临时伤势 / 一次性破损 / 短期特殊造型——只在跨段且易漂移时生产 | 哭花妆（跨3段→生产；只出现1段→不生产） |
| **不生产** | 动作 / 表情 / 临时站位 / 简单持有关系 / 普通背景元素 | 这些全部走状态包 |

**决策过程留在本环节内部，不传给环节 5**——环节 5 只接任务队列。

## 输出：资产生产任务队列

每项：

```
asset_id                 按ID体系编制
asset_type               九分类之一
parent_asset_id          父级资产（C001-E01-A02 的父级是 C001-E01-A01 或 E 层基准）
identity_anchors         身份锚点（跨版本绝对不变：脸型/五官/胎记位置形态）
inherited_attributes     从父级继承的属性
changed_attributes       本版本变化的属性
locked_attributes        本版本内锁死的属性
output_spec_id           输出规格（见环节5）
dependency_order         生产顺序（父级先于子级）
```

# 环节 5：资产生产、固定与注册

## 目标

把资产定义转换成固定图片资产。

## 生产流程

```
读取父级资产 → 选择资产提示词模板 → 选择输出规格 → 编译资产提示词 → 调用图片模型生成
```

**编译规则**：提示词 = 视觉基调压缩版 + 父级继承描述 + 本版本变化描述 + 输出规格控制词。父级的 `identity_anchors` **原样复制**，禁止重新组织语言——重写就漂移。

## 输出规格

| 规格 | 内容（默认约定，可在项目生成配置中调整） |
| --- | --- |
| 人物 4 视图 | 正面全身 / 侧面全身 / 背面全身 / 正面半身特写，同一人物同一造型，中性背景 |
| 场景 9 视图 | 全景 + 四方位中景 + 关键陈设特写×4，同一空间同一光线 |
| 立体道具多视图 | 正/侧/45° 三视图，纯色背景 |
| 平面道具多视图 | 正面 + 使用状态，纯色背景 |
| 附属特征 | 特写 + 在人物身上的位置示意，各 1 张 |

## 固定机制（原文规则）

- 每个资产只生成 **1 个结果**
- **不生成候选组**
- asset_id 绑定唯一文件
- 生成后直接 `fixed`
- 不自动覆盖（要改走环节 12 的人工修改接口）

## 资产生成提示词文件

存 `06_生产提示词/01_资产生成提示词/<类目>/<asset_id>_PROMPT.txt`：

```
资产ID：
资产名称：
资产类型：
调用的父级资产：
身份锚点：
继承属性：
变化属性：
锁定属性：
输出规格：
完整资产生成提示词：
{可直接投喂图片模型的提示词本体}
```

## 输出：资产注册表

`02_全剧资产/asset_registry.json`，每项：`asset_id / entity_id / asset_type / asset_file_ref / effective_scope / status: fixed`。

# 环节 6：段落资产自动绑定

## 目标

为每个 15 秒段落调用**当前正确的**资产版本。输入：段落表 + 状态包 + 资产注册表 + 全剧时间节点。

## 绑定逻辑

| 对象 | 绑定内容 |
| --- | --- |
| 人物 | 当前演化阶段（E层）+ 当前造型版本（A层）+ 固定图片文件引用 |
| 场景 | 当前结构版本 + 当前环境版本 |
| 道具 | **进入状态版本 + 退出状态版本**（段内发生状态跃迁的道具两个都绑） |
| 附属 | 所属人物 + 本段可见状态（可见/被遮挡/暴露瞬间） |

## 关系绑定（空间层）

- 人物位置、人物朝向、人物距离
- 道具持有人、道具空间位置
- 持续状态

## 强制规则（原文）

> 名称只用于人工查看。真正调用资产必须使用 asset_id。

绑定引用的 asset_id 必须在注册表中真实存在且 `status: fixed`。找不到 → 回环节 4 补任务，**不要临时编造**。

## 输出

`bindings.json`（段落资产绑定包），每段列出全部绑定 + 关系。
