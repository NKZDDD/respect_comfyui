# 剧本 → AI短剧视频提示词

把一份原始剧本，处理成**可直接投喂视频生成模型的提示词** + **强一致性的版本化资产库**。

面向 **AI短剧**（不是传统影视）：单集 1~5 分钟，最小生成单位是固定 **15 秒的「段」**。

## 何时用

- 用户给了剧本（或剧本路径），要做成 AI 短剧
- 要拆段、提资产、做分镜、写图片/视频提示词
- 要检查已有素材的前后一致性

不适用：单张图片提示词、无剧情的纯素材生成。

## 最高优先原则

1. **输出给 AI 看，不是给人看。** 干净、结构化、可直接复制。不写导读、不写「以上就是」、不做人类向的变更日志和汇报文档。
2. **全自动优先。** 减少人工判断点。规则能固定就固定，不要设计需要人临场决策的分支。
3. **一致性高于表现力。** 任何时候在「画面更好看」和「和前面对得上」之间选，选后者。

## 状态在项目目录，不在对话

每个剧本一个项目目录。所有中间产物落盘，随时可中断续跑。

```
<项目名>/
├── 00_全局设定/        visual_tone.md        项目视觉基调
├── 01_剧本解析/        segments.json         段级解析结果
├── 02_资产库/
│   ├── 人物形象版本库/  C01-V01.md ...
│   ├── 场景状态版本库/  S01-V01.md ...
│   └── 道具状态版本库/  P01-V01.md ...
├── 03_分镜与提示词/
│   └── 集01/段01/      storyboard.md
│                       image_prompts/镜头01.txt ...
│                       video_prompt.txt
├── 04_生成视频/集01/    段01_raw.mp4  段01.mp4
├── 05_成片/            集01_成片.mp4
└── 06_检查报告/        集01_check.json
```

**开工前先 ls 项目目录**，看已经做到哪一步，从那里继续。不要重跑已完成的步骤。

## 命名规范（全流程强制）

| 对象 | 格式 | 例 |
| --- | --- | --- |
| 集 / 段 | 两位数 | `集01`、`段01`、段编号 `01-05` = 集01第5段 |
| 人物版本 | `C{两位}-V{两位}_{简述}` | `C01-V02_哭泣崩溃` |
| 场景版本 | `S{两位}-V{两位}_{简述}` | `S01-V03_被砸毁后` |
| 道具版本 | `P{两位}-V{两位}_{简述}` | `P02-V02_断裂` |
| 原始视频 | `段XX_raw.mp4` | |
| 可用视频 | `段XX.mp4`（已删头 0.8 秒） | |
| 关键帧 | `镜头XX.png` | |
| 成片 | `集XX_成片.mp4` | |

引用资产时**必须写完整版本 ID**，不能只写人物名。

## 固定参数

| 项 | 值 |
| --- | --- |
| 段时长 | 固定 15 秒 |
| 视频开头裁切 | 固定 0.8 秒 |
| 视频生成输入优先级 | 首帧（上一段尾帧）> 参考图（本段关键帧） |
| 成片拼接 | 硬切，无后期 |
| 目标视频模型 | 即梦 |

## 唯一的人工确认点

**第 1 步产出「项目视觉基调」后停一次，让用户确认。**

理由：视觉基调是强默认，后面每一张图、每一段视频都继承它。定错了后面全错，而且改起来要重跑资产库。

其余步骤连续跑完，不要逐步问「是否继续」。

例外：用户明确说了「只做第 N 步」或传了 `--step N`，就只做那一步。

## 常见错误

- ❌ 段记录里写「林晚」→ ✅ 写 `C01-V02_哭泣崩溃`
- ❌ 同一集内人物形象变了却复用旧版本号 → ✅ 以「段」为最小观察单位判断，变了就新建版本
- ❌ 忘记物理状态继承（上一段哭过，这一段泪痕消失了）
- ❌ 资产核心描述写得太概括（「一个漂亮女生」）→ ✅ 必须详细到能直接当图片提示词用
- ❌ 生成人类向的汇报文档 / 变更日志
