# 第1步：剧情可生成化解析 + 项目视觉基调

整个流程最核心的一步。这一步的信息密度决定了后面所有环节的一致性上限。

产出两个东西：`00_全局设定/visual_tone.md` 和 `01_剧本解析/segments.json`。

## 1.1 结构层级

```
集（时长弹性，1~5分钟）
└── 段（固定15秒）← 核心单位，一切以段为准
    └── 场景（每段必须明确，短剧节奏快，同一集内场景常切换）
```

一集 = N 段。5 分钟 ≈ 20 段。拆段时按情节/情绪的完整性切，但**每段时长固定 15 秒**——如果一个情节撑不满或超出 15 秒，调整该段承载的内容量，不要改时长。

## 1.2 形象版本判断规则

- **以「段」为最小观察单位**
- 同一集内形象发生变化（哭花妆、淋雨、换衣服、受伤）→ 新建版本
- 整集形象不变 → 全集共用一个版本

不要以「集」为单位判断，那样会漏掉同集内的变化。

## 1.3 每段必须记录的字段

一个字段都不能省。空的写「无」，不要删字段。

| 字段 | 说明 |
| --- | --- |
| 段编号 | `01-05` = 集01第5段 |
| 时间信息 | 相对时间 + 绝对时间 + 承接关系。三者都要 |
| 场景状态版本 | 版本ID + 详细描述 |
| 空间与站位 | 主要人物的位置、朝向、彼此距离。**AI 生成最容易在这里出错** |
| 出场人物及形象版本 | 版本ID + 本段的具体状态细节 |
| 关键道具及状态 | 版本ID + 当前位置 + 当前状态 |
| 动作时间线 | 精确到秒，覆盖满 0-15s |
| 对白 | 标注说话人 + 出现在第几秒 |
| 情绪与节奏 | 情绪走向 + 节奏变化 |
| 视觉重点 | 这 15 秒里最该被看到的东西 |
| 连续性备注 | **强制**列出从上一段继承的项 |
| 状态性质 | 临时 / 本集有效 / 永久 |
| 伏笔/关联 | 可空 |

### 字段填写要点

**时间信息** — 三段式，缺一不可：
```
本集开始后约 1分12秒 | 当晚 23:40 | 承接上一段争吵后约30秒
```
短剧节奏快但跨集时间跨度大，不写全会出现昼夜错乱。

**空间与站位** — 要能让画图 AI 直接摆位：
```
林晚蜷缩在沙发左侧，身体侧向右边；周衍站在门口右侧，身体正面朝向林晚，两人相距约2.5米。
```

**动作时间线** — 秒数必须连续覆盖 0-15s，对白落点标在里面：
```
0-4s：林晚低着头，肩膀微微抽动
4-8s：周衍往前走两步，停下
8-12s：林晚缓慢抬头，与周衍对视（对白出现）
12-15s：周衍目光下移，看到地上的狼藉，嘴角收紧
```

**连续性备注** — 这是防一致性崩坏的主防线。逐项列出必须继承的物理痕迹：
```
- 林晚泪痕和花妆继承上一段哭泣结果，必须保留
- 公文包位置继承上一段落地动作（门口地面）
- 周衍肩头雨水未干，与「外面在下雨」逻辑连贯
```
常见继承项：泪痕、妆容、雨水、汗、伤口、衣物褶皱/破损、物品位置、头发凌乱度。

**状态性质** — 决定这个版本会不会进长期资产：
- `临时` — 本段/几段内会恢复（妆花、衣服湿、情绪激动）
- `本集有效` — 整集持续，下集恢复
- `永久` — 疤痕、剪发、房子被烧。**永久变化必须在第2步升级为长期默认版本**

## 1.4 段记录完整示例

```
段 01-05（集01 · 第5段）

- 时间信息：本集开始后约 1分12秒 | 当晚 23:40 | 承接上一段争吵后约30秒
- 场景状态版本：S01-V02_夜晚混乱（本集有效）
  详细描述：只开一盏昏黄台灯，茶几物品被扫落在地，窗帘半开，窗外有雨声。
- 空间与站位：
  林晚蜷缩在沙发左侧，身体侧向右边；周衍站在门口右侧，身体正面朝向林晚，两人相距约2.5米。
- 出场人物及形象版本：
  - C01-V02_哭泣崩溃（临时）
    细节：在 C01-V01 日常家居版基础上，眼妆严重晕开，泪痕未干，头发被抓乱，左肩睡衣滑落。
  - C02-V01_冰冷归来（沿用）
    细节：黑色风衣，肩头和头发有雨水，表情阴沉。
- 关键道具及状态：
  - P01-V01_公文包关闭：放在门口地面（继承上一段动作）
  - P04-V01_台灯：唯一光源，光线微微闪烁
  - P03-V02_水杯打翻：茶几右侧地面，水已洒出
- 动作时间线：
  - 0-4s：林晚低着头，肩膀微微抽动
  - 4-8s：周衍往前走两步，停下
  - 8-12s：林晚缓慢抬头，与周衍对视（对白出现）
  - 12-15s：周衍目光下移，看到地上的狼藉，嘴角收紧
- 对白：
  - 8s C01：「你到底……还要我怎样？」
- 情绪与节奏：从压抑到尖锐对峙，节奏由慢转强
- 视觉重点：两人目光对视的瞬间 + 林晚泪痕特写
- 连续性备注：
  - 林晚泪痕和花妆继承上一段哭泣结果，必须保留
  - 公文包位置继承上一段落地动作
  - 周衍肩头雨水未干，与「外面在下雨」逻辑连贯
- 状态性质：C01-V02 为临时（预计本集内可恢复）
- 伏笔/关联：地上的水杯是林晚刚才情绪激动时扫落的，后续可能被提及
```

`segments.json` 用同样的字段结构，键名用英文，值用中文。

## 1.5 项目视觉基调

只在项目开始定一次，之后所有资产描述和提示词都**默认继承**，不再重复写。

定位：**强默认 + 允许例外**。核心层（1-6项）严格遵守；参考层（7-10项）可按剧情灵活调整；重大剧情转折可临时覆盖，但必须在段记录里备注。

### 模板

```text
【项目视觉基调】

1. 类型定位
- 主类型：
- 副类型/标签：
- 核心情绪关键词：（3-5个）

2. 整体氛围
- 主导氛围：
- 情绪浓度：低 / 中 / 高
- 叙事气质：（克制 / 爆发 / 压抑 / 疏离 / 温暖 等）

3. 色调系统
- 主色调：
- 辅色调：
- 色彩饱和度：低 / 中低 / 中 / 中高
- 色彩对比方式：（柔和过渡 / 冷暖对比 / 高对比 等）
- 整体色温倾向：冷 / 中性 / 暖

4. 光影风格
- 光源偏好：（自然光 / 室内弱光 / 混合光 / 戏剧光 等）
- 光影反差：低 / 中 / 高
- 阴影处理：（柔和 / 硬朗 / 沉重）
- 情绪用光重点：

5. 人物质感
- 皮肤质感：真实 / 轻微磨皮 / 细腻但保留纹理
- 妆造倾向：素颜 / 淡妆 / 精致妆 / 浓妆
- 面部审美：真实自然 / 轻微优化 / 精致立体
- 表情控制：克制内敛 / 自然 / 强烈外放
- 形体与气质关键词：

6. 场景质感
- 空间偏好：（生活化真实 / 略微风格化 / 强烈风格化）
- 陈设与细节密度：简洁 / 中等 / 丰富
- 环境磨损度：（全新 / 正常使用感 / 破旧 / 残破）
- 空气感与氛围粒子：（干净 / 轻微尘埃 / 烟雾 / 雨气 等）

7. 镜头与构图倾向
- 常用景别偏好：
- 构图风格：（稳定居中 / 情绪化偏移 / 压迫构图 等）
- 运镜气质：（静止为主 / 缓慢移动 / 手持感 等）

8. 画质与技术
- 目标清晰度：
- 细节保留程度：
- 是否需要电影级颗粒/噪点：

9. 明确禁止项
- 禁止风格：
- 禁止元素：
- 禁止表现：

10. 参考气质（可选）
- 视觉参考作品/导演/摄影师气质：
```

### 示例（现代都市虐恋短剧）

```text
1. 类型定位
- 主类型：现代都市情感
- 副类型/标签：虐恋、内耗、婚姻危机
- 核心情绪关键词：压抑、隐忍、撕裂、疲惫、克制

3. 色调系统
- 主色调：青灰、冷白
- 辅色调：微弱暖黄灯光
- 色彩饱和度：低
- 色彩对比方式：冷暖微弱对比
- 整体色温倾向：冷

5. 人物质感
- 皮肤质感：真实，保留轻微瑕疵与疲惫感
- 妆造倾向：素颜或极淡妆，强调疲惫
- 面部审美：真实自然，不精致不美颜
- 表情控制：克制内敛，情绪通过微表情传递
- 形体与气质关键词：单薄、紧绷、防备

9. 明确禁止项
- 禁止风格：卡通、二次元、网红美颜、日系清新
- 禁止元素：文字、水印、过度光斑、假笑
- 禁止表现：夸张哭腔表情、过度扭曲面部
```

### 核心描述压缩版

除了完整的 10 项，还要产出一段**压缩成一行的核心描述**，供后续提示词模板的 `【全局风格】` 直接引用：

```text
写实电影感，现代都市情感虐恋，低饱和冷调，青灰为主辅以微弱暖黄灯光，真实皮肤质感，克制压抑，情绪内耗，禁止美颜磨皮、卡通、二次元
```

存在 `visual_tone.md` 末尾，标记为「压缩版（供提示词引用）」。
