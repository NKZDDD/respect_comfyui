# 第7步：视频生成 Prompt（即梦）

针对即梦优化。这一步的规则是**全固定、零判断**的——刻意不做动态决策，因为整个流程要能全自动跑。

## 7.1 固定执行规则

```
1. 首帧   = 上一段视频的尾帧          ← 最高优先级
2. 参考图 = 本段第6步生成的关键帧
3. 生成 15 秒视频
4. 固定删除开头 0.8 秒 → 得到约 14.2 秒可用片段
5. 用处理后片段的尾帧，作为下一段的首帧，循环
```

**不判断场景是否切换，不动态调整优先级。** 所有段一律「首帧 → 参考图」。

### 为什么这样定

即梦对首帧的遵循度最高。全部走首帧，流程极简、段间连贯性最好、AI 执行零判断成本。

代价：真正切换场景时，上一段尾帧会让新场景开头有 1~2 秒「旧场景残留感」。这个代价用**固定删除开头 0.8 秒**来消化，而不是靠临场判断——判断就意味着人工介入，那是这套流程要避免的。

0.8 秒是折中值（保守 0.5 / 推荐 0.8 / 激进 1.0~1.2）。即梦通常 24 或 25 fps，程序可以精准裁帧。这个值可调，改了要同步更新 SKILL.md 的固定参数表。

**第一段没有上一段尾帧**，只用参考图；第一段也照样删 0.8 秒，保持所有段时长一致。

## 7.2 提示词结构

```text
基于首帧和参考图，严格保持{关键一致性特征}一致。

15秒连续画面：
0-Xs：……
X-Ys：……
Y-15s：……

{景别}，{运镜}，动作自然流畅不僵硬，面部清晰不变形，人体结构正常，严格保持一致性，{视觉基调继承描述}。
```

三个部分各有分工：

| 部分 | 作用 | 来源 |
| --- | --- | --- |
| 开头一致性句 | 锁住最容易漂移的特征 | 分镜表的「特别注意事项」+ 资产的「稳定特征锁定」 |
| 时间线 | 描述 15 秒内的连续动作与情绪 | 段记录的「动作时间线」，用自然语言重写 |
| 收尾控制句 | 画质与避错 | 分镜表的「视频生成参数建议」+ 视觉基调 |

## 7.3 写法要点

**开头一致性句要点名具体特征，不要泛泛而谈。**

- ❌ 保持人物一致
- ✅ 严格保持 C01-V02 的惨白脸色、泛红眼眶、发白指节特征

**时间线用自然语言，不要用分镜表的字段式写法。** 即梦吃连续叙述，不吃结构化字段。

时间线的切分**按动作节奏**，不必和分镜的镜头切分一一对应——一段视频是一次生成，镜头切分是给关键帧用的。通常切 2~3 段就够，切太碎即梦反而抓不住重点。

**对白**：写进时间线，标明说话人和内容。即梦不生成语音，但对白会影响口型和表情。

## 7.4 完整示例

```text
基于首帧和参考图，严格保持C01-V02的惨白脸色、泛红眼眶、发白指节特征。

15秒连续画面：
0-7秒：艾薇拉低头，双手死死绞紧身前的衣角，指节明显发白，眼眶迅速泛红，泪水在眼中打转。
7-15秒：她的身体开始明显摇晃，脸色变得惨白，眼神逐渐失焦，用几乎听不见的虚弱声音说出"我……没吃晚饭……"。

近景为主，缓慢推近，动作自然微弱，面部清晰不变形，人体结构正常，严格还原崩溃前兆状态，苍白光线，低饱和，超高清。
```

另一个例子（多人对峙）：

```text
基于首帧和参考图，保持人物面部特征、服装、标志性细节与场景状态一致，林晚左脸疤痕必须清晰可见。

15秒连续画面：
0-5秒：林晚蜷缩在沙发左侧，低头，肩膀轻微抽动，泪痕未干。
5-11秒：周衍从门口向前走两步停下，两人对视，林晚缓慢抬头，第7秒说出"你到底……还要我怎样？"。
11-15秒：周衍目光下移看向地上的狼藉，嘴角收紧。

中景为主，镜头固定，动作自然流畅不僵硬，面部清晰不变形，人体结构正常，严格保持两人站位距离感，昏黄弱光，低饱和冷调，超高清。
```

## 7.5 输出

```
03_分镜与提示词/集01/段05/video_prompt.txt
```

纯文本，内容即提示词本体。同时在同目录写一份 `video_inputs.json` 记录本段的输入引用：

```json
{
  "segment": "01-05",
  "first_frame": "04_生成视频/集01/段04.mp4#last_frame",
  "reference_image": "03_分镜与提示词/集01/段05/keyframes/镜头01.png",
  "trim_head_seconds": 0.8,
  "duration": 15
}
```

第一段的 `first_frame` 写 `null`。

`reference_image` 默认取本段**第一个镜头**的关键帧（因为它对应视频开头）。
