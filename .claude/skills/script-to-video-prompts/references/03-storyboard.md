# 第4-5步：剧情与资产绑定 + 分镜表

第4步把段记录里的人物/场景/道具替换成资产库里的正式版本引用，第5步在此基础上切镜头。

## 4.1 绑定输出顺序

**固定的放前面，要去资产库拿的放中间，剧情内容放后面。** 这个顺序是为了让下游提示词模板能按梯队直接拼接。

| 梯队 | 内容 |
| --- | --- |
| 第一梯队（固定信息） | 段编号、时间信息、视觉基调（引用，不展开） |
| 第二梯队（资产库调用） | 场景绑定、人物绑定、道具绑定 |
| 第三梯队（剧情内容） | 动作时间线、对白、情绪、视觉重点、连续性备注、伏笔 |

## 4.2 绑定强制要求

- 必须使用**完整版本 ID**（`C01-V02_哭泣崩溃`），不能只写人物名
- 人物绑定必须包含**站位与状态**
- 道具必须写明**当前位置和状态**
- 引用的版本 ID 必须在 `02_资产库/` 里真实存在。找不到就回第2步补，不要临时编一个

## 4.3 绑定后的段记录示例

```text
【第一梯队】
段编号：01-05
时长：15秒
时间信息：本集开始后约 1分12秒 | 当晚 23:40 | 承接上一段争吵后约30秒
视觉基调：项目默认

【第二梯队】
场景绑定：S01-V02_夜晚混乱
人物绑定：
- C01-V02_哭泣崩溃 ｜ 站位：沙发左侧，身体侧向右 ｜ 状态：低头，肩膀抽动，泪痕未干
- C02-V01_冰冷归来 ｜ 站位：门口右侧，正面朝向林晚，相距2.5米 ｜ 状态：肩头带雨，表情阴沉
道具绑定：
- P01-V01_公文包关闭 ｜ 位置：门口地面
- P03-V02_水杯打翻 ｜ 位置：茶几右侧地面，水已洒出
- P04-V01_台灯 ｜ 位置：角落 ｜ 状态：唯一光源，光线微闪

【第三梯队】
动作时间线：
- 0-4s：林晚低着头，肩膀微微抽动
- 4-8s：周衍往前走两步，停下
- 8-12s：林晚缓慢抬头，与周衍对视（对白出现）
- 12-15s：周衍目光下移，看到地上的狼藉，嘴角收紧
对白：8s C01「你到底……还要我怎样？」
情绪与节奏：从压抑到尖锐对峙，节奏由慢转强
视觉重点：两人目光对视的瞬间 + 林晚泪痕特写
连续性备注：泪痕/花妆继承上一段；公文包位置继承；周衍肩头雨水未干
伏笔/关联：地上的水杯是林晚刚扫落的
```

# 第5步：分镜表

## 5.1 核心原则

- **分镜颗粒度由剧情决定，不固定镜头数量。** 情绪戏可能 2 个镜头撑满 15 秒，动作戏可能 5 个。不要为了凑数切镜头
- 所有字段服务于后续视频提示词的准确生成与一致性控制
- 镜头时长加起来必须正好 15 秒

## 5.2 每个镜头的完整字段

一个都不能省：

| 字段 | 说明 |
| --- | --- |
| 镜头目的 | 这个镜头存在的叙事理由 |
| 景别 | 远景/全景/中景/中近景/近景/特写 |
| 构图 | 谁在画面什么位置，朝向 |
| 焦点 | 观众视线应该落在哪 |
| 镜头运动 | 静止/微推/推/拉/摇/移/跟/微降 |
| 画面内容 | 这个镜头里实际发生什么 |
| 调用资产 | 完整版本 ID，多个用 `+` 连接 |
| 情绪重点 | |
| 对白落点 | 第几秒说什么，无则写「无」 |
| 特别注意事项 | **一致性风险点**。哪个特征必须可见、哪里容易畸形 |
| 转场 | 硬切 / 本段结束 |

## 5.3 分镜表输出格式

```text
【段编号】01-05
【段时长】15秒
【场景】S01-V02_夜晚混乱
【视觉基调】项目默认

【分镜列表】

1. 镜头01（0-5秒）
- 镜头目的：情绪延续，展示林晚崩溃后的残状态
- 景别：中近景
- 构图：林晚居左，身体侧向右
- 焦点：林晚面部（重点是泪痕与左脸疤痕）
- 镜头运动：静止微推
- 画面内容：林晚蜷缩在沙发上，低头，肩膀轻微抽动，泪痕清晰可见
- 调用资产：C01-V02_哭泣崩溃 + S01-V02_夜晚混乱
- 情绪重点：压抑、残留哭泣
- 对白落点：无
- 特别注意事项：必须清晰露出左脸颊疤痕，手部动作幅度小，避免畸形
- 转场：硬切至下一镜头

2. 镜头02（5-11秒）
- 镜头目的：建立对峙关系，推进冲突
- 景别：中景
- 构图：两人形成对峙，周衍居右
- 焦点：两人面部之间的情绪交流
- 镜头运动：固定
- 画面内容：周衍走进停下，与林晚对视，对白出口
- 调用资产：C01-V02_哭泣崩溃 + C02-V01_冰冷归来 + S01-V02_夜晚混乱
- 情绪重点：对峙、尖锐
- 对白落点：第7秒「你到底……还要我怎样？」
- 特别注意事项：保持两人站位距离感，林晚左脸疤痕可见
- 转场：硬切

3. 镜头03（11-15秒）
- 镜头目的：反应镜头，强化周衍的压抑怒意
- 景别：近景
- 构图：周衍面部为主
- 焦点：周衍眼神与嘴角
- 镜头运动：微降
- 画面内容：周衍目光下移看向地上狼藉，嘴角收紧
- 调用资产：C02-V01_冰冷归来 + P03-V02_水杯打翻
- 情绪重点：压抑怒意
- 对白落点：无
- 特别注意事项：避免面部过度扭曲
- 转场：本段结束

【视频生成参数建议】
- 整体运动幅度：低-中
- 相机运动强度：弱
- 镜头间衔接：以硬切为主，保持节奏紧凑
- 重点控制：人物面部一致性、微表情、站位关系
- 其他：优先保证疤痕、泪痕等关键特征清晰可见
```

段末的【视频生成参数建议】会被第7步用来调整视频提示词的收尾控制句，不要省略。

存到 `03_分镜与提示词/集XX/段XX/storyboard.md`。
