# 第2-3步：版本化资产提取 + AI 可用固定资产库

第2步从段记录里把资产抽出来列清单，第3步把清单变成能直接当图片提示词用的资产文件。两步连着做。

## 2.1 三大资产库

全部支持状态版本。道具也做版本（同一把刀：干净版 / 带血版 / 断裂版），不要只做基础资产。

| 库 | ID 前缀 | 目录 |
| --- | --- | --- |
| 人物形象版本库 | `C` | `02_资产库/人物形象版本库/` |
| 场景状态版本库 | `S` | `02_资产库/场景状态版本库/` |
| 道具状态版本库 | `P` | `02_资产库/道具状态版本库/` |

## 2.2 提取规则

1. **遍历所有段记录**，把出现过的人物形象版本、场景状态版本、道具状态版本全部去重收集
2. **永久变化自动升级为长期默认版本** — 状态性质为「永久」的版本，标记 `是否长期默认：是`，并记录从第几集/段起生效。后续段落默认引用这个版本，不再回退到旧版本
3. **不产出「资产版本变更日志」** — 那是给人看的，这套流程的消费方是 AI

## 2.3 资产文件格式

一个版本一个文件，文件名 = 版本ID + 简述，例如 `C01-V03_受伤留疤.md`。

```text
资产ID：C01-V03
类型：人物形象
名称：林晚-受伤留疤
是否长期默认：是
适用：第5集起
状态性质：永久
来源段：01-12

核心描述：
{一整段连续的详细描述，见下方要求}

稳定特征锁定：
{列出跨版本绝对不能变的特征}
```

场景和道具同样格式，把「类型」换成 `场景状态` / `道具状态`。

## 2.4 核心描述的详细程度

**这是这一步最关键的地方。** 核心描述必须详细到可以直接复制进画图模型当提示词用。

写死所有稳定特征：年龄、国籍/人种、脸型、肤色、五官逐项、发型发色发质、身材、服装（款式+颜色+材质+细节）、气质。

全局风格**不要**写进核心描述——第1步的视觉基调会在提示词模板里统一拼接，重复写会互相打架。

### ✅ 合格示例（人物）

```text
资产ID：C01-V03
类型：人物形象
名称：林晚-受伤留疤
是否长期默认：是
适用：第5集起

核心描述：
22岁中国年轻女性，瘦削瓜子脸，肤色苍白带轻微青灰，左脸颊中部有一道长约2.5厘米的浅褐色浅疤，疤痕边缘轻微凸起。眼睛细长，眼角微微下垂，眼白有血丝，眼神疲惫、倔强又带着压抑的痛苦。眉毛淡而平直，嘴唇干燥微裂，呈暗粉色。头发是自然黑色长直发，发丝细软，此刻有些潮湿凌乱，几缕贴在脸颊和脖颈上。身材纤细单薄，穿着一件宽松的浅灰色棉质长袖睡衣，领口较大，微微敞开到锁骨，袖口有些皱褶，下摆盖过臀部。整体气质虚弱、隐忍、情绪压抑，带着刚哭过后的残痕。

稳定特征锁定：左脸浅疤位置与形态固定、肤色苍白、瘦削脸型、细长眼型、自然黑长直发。
```

### ✅ 合格示例（场景）

```text
资产ID：S01-V03
类型：场景状态
名称：出租屋客厅-被砸毁后
是否长期默认：是
适用：第5集起

核心描述：
破旧的一室一厅出租屋客厅，面积约20平米，墙面是发黄的白墙，有多处污渍和裂纹。浅色木地板上散落着打翻的水杯、文件和几件衣服。茶几被掀翻在地，玻璃桌面有裂痕。沙发是深灰色旧布艺沙发，坐垫变形，上面扔着一条皱巴巴的米白色毛毯。唯一光源是角落一盏落地灯，发出昏黄不稳定的光，在墙上投下凌乱的影子。窗帘是半透明的白纱帘，此刻半拉着，窗外是夜晚城市的模糊光点。空气中仿佛有尘埃，整体氛围混乱、压抑、暴力过后的残局感。

稳定特征锁定：发黄白墙、深灰布艺沙发、落地灯位置、木地板材质、空间布局固定。
```

### ✅ 合格示例（道具）

```text
资产ID：P02-V02
类型：道具状态
名称：项链-断裂
是否长期默认：是
适用：第8集起

核心描述：
一条细款白金项链，链身纤细光滑，原本挂着一枚小小的圆形吊坠（吊坠正面刻有简单的字母）。此刻项链从中间完全断裂，断口处链节变形，吊坠和半截链条落在地上，另一半还残留着轻微的拉扯痕迹。金属表面有细微划痕，在光线下反射冷白光泽。整体看起来刚被暴力扯断，带着冲突后的痕迹。

稳定特征锁定：细款白金材质、圆形小吊坠、断裂位置与形态。
```

### ❌ 不合格

```text
核心描述：一个22岁的漂亮女生，穿着睡衣，看起来很难过。
```
太概括，画图 AI 每次都会画出不同的人。

## 2.5 稳定特征锁定

「稳定特征锁定」是跨版本的不变量。同一人物的 V01 / V02 / V03，稳定特征必须完全一致——变的只是状态（妆、衣服、情绪、伤）。

写新版本时，先读同人物的已有版本，把「稳定特征锁定」原样抄过来，再改状态部分。这是防止「换脸」的关键。

## 2.6 资产可视化提示词

给每个资产生成定妆图/参考图时用这个模板：

```text
{项目视觉基调压缩版}，{资产核心描述}，{生成控制词}
```

`生成控制词` 固定用：
```text
单人正面半身，中性背景，均匀光照，超高清，细节清晰，避免手部畸形、多余手指、文字、水印
```
（场景资产改成「空镜，无人物」；道具资产改成「单品特写，纯色背景」）

出图存到对应资产目录下，与 `.md` 同名。
