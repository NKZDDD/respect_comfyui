# 第6步：图片生成 Prompt（剧情关键帧）

**每一个镜头都生成一张关键帧。** 一段通常 2~5 个镜头，数量不多，不要挑重点镜头生成。

这些图不只是给人预览的——它们是第7步喂给视频模型的**参考图**，直接决定视频画面质量。所以要够结构化、够详细。

## 6.1 结构化模板

```text
【全局风格】
{项目视觉基调压缩版}

【场景】
{场景版本ID + 详细状态描述}

【人物】
- {人物版本ID}：{完整核心描述}。当前状态：{本镜头的具体站位、动作、表情、情绪细节}
- {人物版本ID}：{完整核心描述}。当前状态：{本镜头的具体站位、动作、表情、情绪细节}

【道具】
- {道具版本ID}：{状态与位置}

【构图与镜头】
景别：{}
构图：{}
焦点：{}
镜头运动感：{}
画面重点：{}

【光影与情绪】
光影：{}
情绪氛围：{}

【技术要求】
超高清，细节清晰，严格还原已定义的人物与场景资产特征，避免手部畸形、多余手指、多余肢体、文字、水印、模糊面部。
{从项目视觉基调中继承的画质与质感描述}
```

## 6.2 填写规则

- **【全局风格】** 直接抄 `visual_tone.md` 的压缩版，不要每次重写
- **【场景】/【人物】/【道具】** 的描述部分**从资产库文件里原样复制核心描述**，不要重新组织语言——重写就会漂移，一致性就崩了
- **「当前状态：」** 后面才是本镜头特有的内容，来自分镜表的「构图」「画面内容」「情绪重点」
- **【构图与镜头】/【光影与情绪】** 来自分镜表对应字段
- **【技术要求】** = 固定避错句（一字不改）+ 视觉基调里的画质与质感描述

### 【技术要求】为什么这么写

它解决的是**生成质量**问题，不是风格问题。拆成两部分：

| 部分 | 是否通用 | 说明 |
| --- | --- | --- |
| 固定避错句 | 通用，一字不改 | 手部畸形、多余手指、文字水印是 AI 绘图最常见的翻车点 |
| 继承视觉基调 | 随剧变化 | 「电影感」对甜宠轻喜剧不一定合适，所以不写死，从基调里继承 |

## 6.3 完整示例

```text
【全局风格】
写实电影感，现代都市情感虐恋，低饱和冷调，青灰为主辅以微弱暖黄灯光，真实皮肤质感，克制压抑，情绪内耗，禁止美颜磨皮、卡通、二次元

【场景】
S01-V03_被砸毁后：破旧一室一厅，发黄白墙有污渍裂纹，浅色木地板散落物品，深灰色旧布艺沙发，茶几掀翻，落地灯发出昏黄不稳定光线，窗帘半拉，夜晚，混乱压抑的残局氛围

【人物】
- C01-V03_受伤留疤：22岁中国年轻女性，瘦削瓜子脸，肤色苍白带青灰，左脸颊中部有一道2.5厘米浅褐色浅疤，眼睛细长带血丝，眼神疲惫倔强，自然黑长直发有些潮湿凌乱，穿着宽松浅灰色棉质睡衣。当前状态：坐在沙发左侧，身体微微侧向右，抬头与对面的人对视，泪痕未干，表情疲惫而倔强，肩膀还有轻微紧绷感
- C02-V01_冰冷归来：成年男性，冷峻面容，穿黑色风衣，肩头和头发带着雨水湿意，气质强势冰冷。当前状态：站在门口右侧，身体正面朝向林晚，与她相距约2.5米，停下脚步，正与林晚对视，表情冰冷压抑

【道具】
- P01-V01_公文包关闭：放在门口地面
- P03-V02_水杯打翻：茶几右侧地面，水已洒出

【构图与镜头】
景别：中景
构图：两人形成对峙，林晚居左，周衍居右
焦点：两人面部之间的情绪交流，林晚左脸疤痕清晰可见
镜头运动感：固定镜头
画面重点：对峙感与眼神交锋

【光影与情绪】
光影：以落地灯昏黄光为主，人物面部半明半暗，阴影较重
情绪氛围：压抑、尖锐、对峙

【技术要求】
超高清，细节清晰，严格还原已定义的人物与场景资产特征，避免手部畸形、多余手指、多余肢体、文字、水印、模糊面部。
真实皮肤质感保留纹理与轻微瑕疵，低饱和冷调，中高光影反差，轻微电影级颗粒。
```

## 6.4 输出

一个镜头一个文件：

```
03_分镜与提示词/集01/段05/image_prompts/镜头01.txt
                                        镜头02.txt
                                        镜头03.txt
```

纯文本，不加 markdown 代码块包裹，不加说明文字——文件内容就是可以直接复制粘贴进画图模型的提示词本体。

出图后存到同目录的 `keyframes/镜头01.png`。
