# Rask SRT 说话人助手 1.0.1

用于在线 Rask 项目编辑页面。导入带 `[SPEAKER_00]` 等标记的 SRT，仅按字幕起止时间匹配片段，再通过页面的说话人下拉框选择对应角色。原文或译文 SRT 均可，正文不参与匹配。

## 安装到 Chrome / Edge

1. 将 ZIP 解压到一个固定文件夹。不要在 ZIP 内直接打开文件。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」。
4. 选择**包含 manifest.json 的文件夹**。
5. 在浏览器扩展菜单中固定「Rask SRT 说话人助手」。

不需要填写账号、API Key，也不需要启动 Studio。升级时覆盖同一文件夹中的插件文件，在扩展管理页点击「重新加载」，再刷新 Rask 网页。

## 使用

1. 打开 `https://app.rask.ai/` 中需要修改的项目，等待字幕列表载入，关闭字幕搜索或筛选。
2. 点击浏览器工具栏里的插件图标，右侧出现「说话人助手」。
3. 导入 UTF-8 编码的 SRT。插件自动从顶部向下滚动字幕列表，扫描所有能加载的片段。保持页面前台，不要同时手动滚动、编辑字幕或切换项目。
4. 检查预览中的「待修改、已一致、未找到、跳过」。只有「待修改」会被点选。
5. 点击「应用说话人」。插件逐条打开下拉框、选择对应内部值，完成后再滚动核对一次。可点击「停止」中断，已经点选的记录会保留。
6. 检查 Rask 的保存提示。插件的“页面复核通过”只证明当前页面中的值一致；**刷新网页后重新导入 / 扫描，可以检查修改是否已被服务端保存**。
7. 可点击「导出记录」，保存匹配结果、修改前后的说话人及异常原因。记录仅存在当前标签页内存，刷新或关闭前请先导出需要保留的记录。

右上角 `−` 收起面板，`×` 隐藏面板；再次点击插件图标可打开。隐藏面板不会停止任务，需要停止时请点击「停止」。

插件只处理说话人选择，不修改字幕原文或译文，不点击 Translate、Apply changes、生成视频、配音或口型等按钮。

## SRT 格式与匹配规则

```srt
0
00:00:00,120 --> 00:00:10,420
[SPEAKER_02]: ل

1
00:00:27,420 --> 00:00:34,000
[SPEAKER_04]: وش ده؟ أنا وين؟
```

- 支持从 0 或 1 开始的字幕序号、阿拉伯语、多行正文、UTF-8 BOM 和 Windows 换行。
- 只比较起止时间（沿用各允许 50 毫秒差异的规则），不校验正文、语言或标点。
- 不用 SRT 序号直接定位页面行，不按 Speaker 显示数字猜选。插件读取菜单选项的实际 `data-value="SPEAKER_XX"`，即使角色改了显示名也按内部值匹配。
- 相同时间的重复条目、无法唯一匹配、目标说话人不存在、扫描后被人工改动的片段会跳过。
- SRT 格式错误会阻止整个导入，避免丢弃错误条目后继续操作。
- 可以使用原文或译文 SRT；两者正文即使完全不同，只要时间唯一匹配就可选择说话人。插件不会把 SRT 正文写入网页。

## 懒加载 / 虚拟列表

提供的网页采用 React Virtuoso。保存的 HTML 中只有索引 0～4 的五个字幕节点，下面用约 4106 像素的空白占位，而提供的 SRT 有 31 条。

因此，“一次查询所有字幕节点”不能读取整个项目。本插件分段滚动字幕容器、等待渲染稳定、重新查找当前 DOM，并在完成后再次滚动核对。超时、缺行或页面切换不会计为全部成功。

**本地保存的 HTML 不是完整项目备份**。如果没有在线页面运行所需的数据，滚动无法补出缺失条目；请在在线项目内使用。

## 验证范围和隐私

开发验证使用了提供的 HTML 结构、31 条真实 SRT 数据，以及会销毁并重新创建片段的离线浏览器测试页。测试包含渲染延迟、菜单缺少目标选项、中途停止、页面值回退及缺行等情况。

未在你的登录账号中实测服务端保存。Rask 改版导致选择器失效时，插件会停止或报告未匹配，需要更新适配。

SRT 在本机浏览器解析，插件没有自己的上传接口，不读取 Cookie 或 API Key。通过网页点选说话人后，Rask 自身可能按其正常行为向服务器保存修改。

仅申请 `activeTab` 和 `scripting` 权限，点击插件后才访问当前标签页；入口限制为 `app.rask.ai` 的项目页面。

技术依据：[Chrome activeTab](https://developer.chrome.com/docs/extensions/develop/concepts/activeTab)、[React Virtuoso](https://virtuoso.dev/react-virtuoso/)、[MUI Select](https://mui.com/material-ui/react-select/)。

## 开发验证

基础检查运行 `node --test core.test.cjs`。原始素材不入库；未设置 `RASK_SAMPLE_SRT` 时，真实 SRT 样本检查会明确跳过。

完整离线回归需安装 Python 的 `playwright`、`beautifulsoup4` 和 Playwright Chromium，将 `RASK_SAMPLE_SRT`、`RASK_SAMPLE_HTML` 环境变量分别指向原始 31 条 SRT 与保存的 Rask HTML，再运行 `python browser_test.py` 和 `python extension_load_test.py`。这些测试针对原始回归样本的结构，不能替换为任意项目材料。截图、导出记录及浏览器配置写入被 Git 忽略的 `_test/`。

验证成功后运行 `python package_extension.py` 生成发布包；发布包仅包含插件代码与使用说明，不包含测试素材或浏览器配置。
