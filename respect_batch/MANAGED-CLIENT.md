# 在线授权批量版

日期：2026-10-29。客户端版本：2026.10.29.2。

此前对外包在编译时封装服务商 Key 和固定模型目录，后台调整授权无法影响已发出的程序。
新版只在登录后取得授权，Key 保留在进程内存，不写进 EXE、config.json 或用量记录。
生成仍由客户端直连服务商；隐藏界面字段不等于防止运行时提取。未增加余额、价格、扣费或退款。

## 管理员

1. 升级现有登录服务至 1.10.2，新增 `batch`（对外批量版）版本类别，原账号和 Key 库不变。
2. 构建客户端后，在“客户端版本 → 测试登记”导入 `batch-registration.json`。此操作不推送 Studio 更新。
3. 在原 Key 库命名 Key、绑定模型，再给账号勾选条目。一个服务商可以分配多把 Key；重叠模型按后台排序选择第一把，不做失败换 Key。
4. 未绑定模型时按每把 Key 查询模型；查询失败不会回落到其他 Key 或全量模型目录。
5. 使用公网图片参考的模型需要给账号分配原有 R2 上传权限。客户端只请求短期上传链接，不接收 R2 长期凭据。现有服务端不支持参考视频上传，勿给这类任务添加参考视频。
6. 在账号“用量对账”中按 Key 和时间查看记录及导出 CSV；导出的模型列可用于分模型核算。

本版包含批量项目现有 17 家服务商适配器。后台可调整这些适配器支持的模型和 Key；新协议/新服务商仍需适配客户端。未支持的授权会在界面提示，不会偷偷改用其他线路。
同一账号在 Studio 与批量版使用同一组授权；现有后台用量按账号合并，尚未增加按应用分账。可以给批量用户创建单独账号。

## 用户

推荐运行 `Respect-Batch-Setup-2026.10.29.2.exe` 安装，从“Respect 批量创作”快捷方式启动。便携使用时将 `RespectBatch-User.exe` 和 `batch-build.json` 放在同一目录。使用管理员提供的账号登录。
页面只显示已授权模型和名称，不提供服务商地址、个人备用 Key 或导入配置入口。
点击“刷新后台配置与模型”同步管理员变更。正在跑的批次先停止新任务并等待收尾，再刷新或切换账号。
每次新批次强制在线校验，排队中的任务提交前复查账号及 Key 授权；已发任务继续取回，不因登录失败重新生成。
点击“软件更新”可检查、下载并查看进度，校验通过后点击“重启完成更新”。启动会检查版本，强制更新后登录前也能更新。有运行任务时先等待收尾。安装器只替换批量程序和版本文件，不覆盖 Studio 或用户数据。首次从 2026.10.29.1 升级须手动安装本次安装器。

用量按一次真实生成提交计一条，轮询和重复上报更新同一事件。明确失败可按设置重试，每次新提交分别记账。
已返回任务 ID 后取回失败记“待取回”；网络中断等不能判断是否提交成功时记“结果不明”，不自动重发。
跳过已有成品、未授权和上传前失败不增加生成次数。
记录暂存在 `%LOCALAPPDATA%/Respect-Batch-User/usage-outbox.sqlite3`，连接恢复且原账号登录后补传。启动后中断中的事件转为待确认，不伪装成失败。
客户端上报只供对账，不是服务商实际扣费证明。故意修改或绕开客户端的调用无法靠这些记录保证覆盖。

## 构建与验证

在 respect_batch 目录执行：

```powershell
py -m pytest
py tools/build_release.py --build D:/Respect-Batch-build-20261029 --stage-only
# 正式构建去掉 --stage-only；构建不读取任何发行 profile 或本地 config.json。
```

开发版与个人版入口保持原行为。旧封装版不会自动获得登录能力，须换发新在线授权包。

构建安装器：`py tools/build_installer.py --payload 构建目录/delivery --makensis NSIS路径/makensis.exe`。
上传发布：`py tools/upload_update.py --release 构建目录/delivery/release.json --config 管理员R2配置.json`，只读 upload 字段，发布清单不含凭据。R2 使用 batch-updates/batch 独立目录，上传后在服务端选择“对外批量版”导入 release.r2.json 并发布。

服务端 application=studio/batch 管理独立校验开关，旧 Studio 客户端兼容。Key 库仍通用。批量使用已有批量适配器，未直接加载 Studio 的远程 Python 适配包。

验证记录见本次交付 VALIDATION.json；验证没有发起付费生成。
