## 构建

使用 Python 3.12 虚拟环境安装 `requirements-release.txt`，执行：

```powershell
.\.release-venv\Scripts\python.exe tools\build_release.py --profile release-private\profile.json
```

默认 4 路 C 编译、O1 优化；工具缓存在项目短路径，避免 Windows AppData 路径长度问题。
需要继续本轮未交付构建时可用 `--reuse-build <构建号>`。
只分发 `release_main.dist` 目录，不能附带源码、私密配置或构建暂存目录。

运行 `tools/verify_release.py <EXE路径>` 验证实际发行程序；此脚本不调用付费生成。
