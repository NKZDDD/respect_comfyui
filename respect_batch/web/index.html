跑批页填的「同时跑几条」之上还有两层：每家一个配额、全局一个总闸。
实际在跑的 = 三个数里最小的。混着跑几家时靠它们防止把某一家打爆 ——
打爆的表现不是「429 太快了」这种明白话，多半只是「生成失败」，看不出是自己撞的自己。
