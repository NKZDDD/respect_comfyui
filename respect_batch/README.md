# Respect 批量并发

把项目里 **17 家服务商**的出图 / 出视频能力整成一个能并发跑的小程序。

**为什么有它**：ComfyUI 一次只推进一个节点。一条视频要跑几分钟，图里排 20 条
就老老实实串行等 20 次。这里 20 条同时发出去，总耗时约等于最慢那一条。

实测（12 条任务，每条 1 秒）：

| 并发 | 耗时 |
|---|---|
| 1 路 | 12.2s |
| 6 路 | 2.2s |
| 12 路 | 1.2s（**10.2 倍**）|

**独立程序**，运行时不依赖 `script-to-video-studio`，它删了也照跑。
（服务商那 17 个文件的起点是从 studio 拷来的 —— 里面每条注释都是踩坑换的，
重写一遍等于把坑再踩一遍。之后两边各自维护。）

---

## 怎么用

```
py run.py
```

浏览器会自己开 `http://127.0.0.1:8790`。关掉黑窗口就是退出。

第一次进去先点 **设置**：

- **服务商密钥** —— 一家一行。已经在 Studio 里填过的，点「从 Studio 导入密钥」
  一次性拷过来（拷完两边各改各的，**不同步**）。每家旁边有「自检」。
- **参考图上传** —— 只在你要给「只收公网链接」的家（鹤 SD2、一手、智）
  带参考图时才需要。填 R2 / OSS / COS / MinIO。
- **并发上限** —— 见下面「三层闸」。

然后回 **跑批** 页：选服务商 → 选做什么 → 选模型 → 提示词一行一条 → 填并发数 → 开跑。

### 提示词怎么写

一行一条。可选用 `|` 分三段：

```
提示词
提示词 | 参考图1;参考图2
提示词 | 参考图1;参考图2 | 输出文件名
```

- 参考图填**本机绝对路径**或 `http` 链接
- 空行、`#` 开头的行跳过 —— 不跑的那条注释掉就行，别删（删了就想不起来写过什么）
- 输出文件名前面会**无条件加序号**：重名会互相覆盖，而覆盖之后你以为跑了 20 条、
  硬盘上只有 12 个文件，状态还全是「完成」

### 命令行（脚本 / 定时任务用）

```
py run.py run --provider paisio --kind video --model sd2-pro-720p \
              --file tasks.txt -j 8 --out D:\out
```

有失败就非 0 退出，CI 里能判。

## 三层闸

同时在跑的条数 = **三个数里最小的那个**：

1. **批内并发** —— 跑批页填的那个数
2. **每家配额** —— 设置页里逐家填（跨批共享）
3. **全局总闸** —— 所有在途请求的总上限

为什么不是一个 `-j N` 了事：多家混跑时，按最保守的那家设 N 就浪费，
按最宽的设就会把某一家打爆 —— 而打爆的表现不是「429 太快了」这种明白话，
多半只是「生成失败」，看不出是自己撞的自己。

**第四层：按账号排队。** HVTALD 这种**一个账号同时只能跑一条**的家，
粒度是账号不是服务商 —— 同一家 3 个账号该能同时跑 3 条，每个账号内部严格串行。
它的并发上限**就是你配了几个账号**，并发数填再大也没用。
在设置里那一家的密钥框里多粘几个账号（换行或分号隔开）就是多几路。

## 四条花钱纪律

1. **成品已存在就跳过。** 跑批中断重来是常态，重跑一遍等于再付一次钱。
   （不想跳过就把「成品已存在就跳过」的勾去掉。）
2. **只重试技术失败。** 提示词违规、余额不足、密钥错 —— 重试多少次都一样，
   还各扣一次。按错误类型分，只有 `retryable` 才重投。
3. **有的家一次都不能重投。** 小霸龙文档原文：创建 POST 只能提交一次、
   客户端不得自动重试 —— 网络超时也可能已经越过计费边界。
   见 `core/batch.py` 的 `NO_RETRY`。
4. **整批致命就整批停。** 余额耗尽 / 密钥失效时，剩下的一条都不发，
   并且**报成「未发」而不是「失败」** —— 报成失败会让人以为被扣了那么多次，
   然后去查账单查半天。

## 参考图：三种形式，给错了不会报错

各家要的形式**互相矛盾**，而给错的后果不是报错，是**参考图被静默丢掉照样出图**——
图出来了、任务标「完成」，只有脸不是本人，几百张里靠肉眼发现。

| 声明 | 要什么 | 谁 |
|---|---|---|
| `bytes` | multipart，真文件字节，**给链接会被丢掉** | 超模图生图、坤鸡 edits |
| `url` | 只收公网链接，**给 data URI 会被丢掉** | 鹤 SD2、一手、智 |
| `data_uri` | 图片内容或链接都行 | 其余多数 |

程序按各家自己的声明分派（`core/refs.py`）。碰上 `url` 那类又没配对象存储时
**硬停**，不静默降级。0 字节的参考图也拦 —— 它在每条分支上都过得去，
服务商收到的是「有参考图」，实际什么都没有。

## 加一家服务商（不用改程序、不用重新打包）

写一个继承 `Provider` 的类，丢进 `<数据目录>/providers/`，
在设置页点「重新扫描」。数据目录在页面右上角显示，通常是
`%LOCALAPPDATA%\Respect-Batch`。

只要求：给 `id` / `name` / `supports`，实现 `capabilities()` 和
`generate_image` / `generate_video`。`capabilities()` 返回的结构直接驱动界面，
不用改一行前端。参考 `core/providers/base.py` 和随便哪一家的实现。

## 产物和记录

- **成品**：你指定的输出目录
- **每次跑批的记录**：`<数据目录>\runs\<批次号>\`
  - `manifest.json` —— 每条的服务商、模型、耗时、重试次数、失败原因（**不含密钥**）
  - `log.jsonl` —— 逐条追加，中途被强杀也留得下

## 打包成 exe

```
pip install pyinstaller
pyinstaller "Respect批量并发.spec" --noconfirm
```

出来的在 `dist\` 下，是一个目录（不是单文件 —— 单文件每次启动都要自解压，
几十 MB 冷启动好几秒，而这是「想起来就双击一下」的用法）。

⚠ 打包有两个**漏了不报错、只是少东西**的坑，spec 里已经处理，改动时别碰：
`web/index.html`（漏了浏览器打开是 500）和 17 家服务商的 `hiddenimports`
（漏了程序照跑、下拉框是空的）。
